# The important problem I found

In:

```text
cortex/stream.py
```

your constructor creates:

```python
self.callbacks = {}
```

but later `_register_callback()` uses:

```python
self._callbacks
```

Specifically, the code does:

```python
existing = self._callbacks.get(stream_name)
```

and later:

```python
self._callbacks[stream_name] = callback
```

However, `self._callbacks` is **never initialized**.

You initialized:

```python
self.callbacks
```

instead.

Therefore, when this line in `run_live.py` executes:

```python
self.streams.subscribe_mental_commands(
    token,
    session.id,
    on_prediction_raw=_raw_message_queue.put
)
```

the subscription can reach the callback-registration code and hit:

```text
AttributeError:
'StreamManager' object has no attribute '_callbacks'
```

### Fix

In `cortex/stream.py`, change:

```python
self.callbacks: dict[str, Callable[[dict], None]] = {}
```

to:

```python
self._callbacks: dict[str, Callable[[dict], None]] = {}
```

That is the first fix I would make.
