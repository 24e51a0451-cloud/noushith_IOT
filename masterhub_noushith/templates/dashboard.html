📖 Neural Gestures & Arrow Key Mappings

MasterHub maps 4 primary mental commands and manual arrow keys across all workflow phases:

🧠 PUSH ↑ Up
Select domain · Confirm device · Move forward / accelerate
🧠 PULL ↓ Down
Step back one phase · Reverse mobility · Turn power off
🧠 LEFT ← Left
Previous item · Steer left · Volume down / prev track
🧠 RIGHT → Right
Next item · Steer right · Volume up / next track
⚡ Ordered Multi-Step Combinations (Relax to Neutral Between Commands):
Left ➔ Right (← + →) : Stop Action (Robot Car & Wheelchair)
Pull ➔ Left (↓ + ←) : Left 360 Spin (Robot Car & Wheelchair)
Pull ➔ Right (↓ + →) : Right 360 Spin (Robot Car & Wheelchair)
Push ➔ Right (↑ + →) : Instant Back to Previous Phase
Push ➔ Left (↑ + ←) : Instant Return to Main Menu / Domain Selection
Right ➔ Push (→ + ↑) : Media Volume Up
Right ➔ Pull (→ + ↓) : Media Volume Down
📘 MasterHub User Guide & Architecture
📄 View Raw .MD

1. System Overview

MasterHub is an intelligent routing hub connecting EMOTIV Cortex BCI Headsets, IoT Smart Relays, PC Desktop Automation Agents, and Robotics mobility platforms into an integrated state-machine architecture.

2. Quick Start Steps

  1. Open EMOTIV Launcher: Ensure EmotivBCI / Cortex service is running on your machine.
  2. Connect Headset: Open the BCI Headset drawer from the sidebar or click the header [BCI] pill.
  3. Load Trained Profile: Select your trained profile to begin streaming live EEG mental commands.
  4. Enable Control Mode: Click "Enable Control" in the Neural HUD or drawer to route actions.

3. Supported Domains

  • 🏠 IoT Smart Home: Relays, Lights, Fans, Temperature & Environmental telemetry.
  • 💻 PC Agent: Chrome browsing, Gmail composing, Notepad, Media controls via agent_H.
  • 🤖 Embedded Robotics: 4WD Smart Car, Wheelchair mobility commands over MQTT & UART.
  • 🧠 AI / ML Pipeline: Vision, Speech, and Neural Gesture routing.

4. Safety & Temporal Windows

MasterHub uses temporal countdown windows (2s, 4s, 8s) to prevent accidental firing. For headset commands, Stop Control cancels the pending frame. Neutral readies the next gesture and stops motion; it does not cancel a navigation combination.
